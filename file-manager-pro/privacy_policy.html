Privacy Policy

File Manager Pro - File Explorer (com.aaatech.fileexplorer.pro) · Last updated: March 2026

This Privacy Policy explains how File Manager Pro - File Explorer (the "App"), published by AAATechnologies ("we", "us", "our"), handles your data and privacy. File Manager Pro is 100% ad-free. Your files, documents, and personal data remain stored locally on your device. We do not upload your files to any external server.

1. 100% Ad-Free Experience

File Manager Pro contains no advertisements and does not use any advertising networks or ad-tracking SDKs.

2. File Access & Local Storage

To function as a complete file explorer, the App requires access to your device's storage (including the All files access / MANAGE_EXTERNAL_STORAGE permission on Android 11 and above):

  • Local Storage Operations: The App accesses files on internal storage, SD cards, and connected USB OTG drives to allow you to browse, copy, move, rename, delete, search, compress (ZIP), and view your files.
  • Storage Analysis: The storage analysis feature inspects file metadata (file sizes, file types) directly on your device to help you identify large files and free up space.
  • Built-in Text Editor: Text files and notes created or edited in the App are saved only on your local storage.
  • Data Isolation: None of your files, documents, photos, audio, or video files are uploaded, transmitted, or shared with us or any third party.

3. Transfer to PC (Built-in FTP Server) & Network Connections

  • Transfer to PC (FTP Server): When you enable the "Transfer to PC" feature, the App starts a local FTP server using an Android Foreground Service. This allows you to access and transfer files between your phone and a computer over your local Wi-Fi / local area network (LAN). All transfers occur directly on your local network. No external servers or cloud services are involved. During an active transfer, the App holds a wake lock (WAKE_LOCK) to keep the CPU active and prevent interrupted transfers.
  • Remote FTP/FTPS Connections: If you use the App to connect to external FTP or FTPS servers, connection parameters and login credentials you enter are stored securely on your device and are used only to establish connections requested by you.

4. App Analytics & Service Diagnostics

To improve app performance and user experience, the App uses Google Firebase services:

  • Google Firebase Analytics: Collects anonymous, aggregated statistics about feature usage, screen views, device model, operating system version, and general app interaction metrics. No personal file data or file contents are included in analytics.
  • Google Firebase Remote Config: Helps manage app configuration settings and feature flags dynamically. It transmits basic app version and device model information.
  • Google Firebase Crashlytics: Collects crash reports and diagnostic stack traces when an error occurs. These reports contain device hardware specs, OS version, and app state at the time of the crash, helping us fix technical issues. Crash reports never contain your personal files or folder contents.

Data processed by Firebase services is handled in accordance with the Google Privacy Policy and Firebase Privacy and Security Guidelines.

5. Optional Permissions

  • Notifications (Android 13+): Used to display status notifications while the FTP Server (Transfer to PC) foreground service is active.
  • Accessibility Service (Optional): The App includes an optional feature to force-stop other applications. This requires Accessibility Service permission only if you choose to enable it. When active, the service automates navigation within Android's system Settings screen to locate and tap the "Force stop" button for apps you select. It does not collect, record, or store any data about you or the apps it stops, and it performs no actions beyond the specific force-stop interaction you initiate.
  • Superuser / Root Access (Optional): On rooted devices, root permissions allow browsing system directories if explicitly granted by the user.
  • Installed Applications (Optional): The App includes an optional "Apps" section that lists the applications installed on your device, using the Android PackageManager API. This information is queried and displayed locally only; the list of your installed apps is never uploaded, transmitted, or shared with us or any third party.

6. Data Security

Your files are protected by standard Android operating system security models and app sandboxing. Because your files remain on your device, we recommend securing your device with a PIN, pattern, or biometric lock.

7. Children's Privacy

The App is a general-purpose utility and is not directed at children under the age of 13. We do not knowingly collect personal information from children.

8. Changes to This Privacy Policy

We may update our Privacy Policy from time to time. Any updates will be published on this page with a revised "Last updated" date.
