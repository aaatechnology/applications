# AAATechnologies Apps

Static website listing AAATechnologies' Android apps: one listing page plus a details page per app, with links to Google Play.

## Structure

```
index.html              App listing
<slug>/index.html       Details page per app
assets/site.css         Shared stylesheet
assets/icons/           App icons (from Google Play)
tamil-astrology/legal/  Astrosoft Tamil terms and privacy policy (hand-written)
gen.py                  Generator for the listing, details pages, CSS and icons
```

## Updating pages

The listing, details pages, `assets/site.css` and icons are generated by `gen.py`. Make changes in `gen.py` rather than in the generated files, since each run overwrites them.

`gen.py` reads saved Google Play pages from `play/<package>.html` and writes to `applications/`, so run it from the parent directory (network access is needed to download icons):

```sh
cd ..
python3 applications/gen.py
```

To add an app, add a `(package, slug, name)` entry to the `apps` list in `gen.py` and save its Play Store page as `play/<package>.html`.

The pages under `tamil-astrology/legal/` are not generated; edit them directly.

## Preview

No build step. Open `index.html` in a browser, or serve the folder:

```sh
python3 -m http.server
```
